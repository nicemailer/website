---
title: Les touches
description: Les touches de tous les jours. Appuyez sur ? dans l'application pour les voir toutes.
order: 5
---

Vous n'avez rien à apprendre : tout a son article de menu ou son clic. Mais chaque touche apprise vous épargne un aller-retour vers la souris, des dizaines de fois par jour. Dans l'application, <kbd>?</kbd> affiche toutes les touches, regroupées par usage.

Certaines touches sont un **préfixe** : <kbd>;</kbd>, <kbd>m</kbd>, <kbd>s</kbd> et <kbd>v</kbd> ouvrent un petit menu qui liste les secondes touches, pour que vous n'ayez jamais à les retenir.

## Se déplacer

| Touche | Action |
| --- | --- |
| <kbd>j</kbd> <kbd>k</kbd>, ou <kbd>↓</kbd> <kbd>↑</kbd> | Conversation suivante, précédente |
| <kbd>⌃</kbd> <kbd>d</kbd> <kbd>⌃</kbd> <kbd>u</kbd> | Une demi-page plus bas, plus haut |
| <kbd>⌃</kbd> <kbd>j</kbd> <kbd>⌃</kbd> <kbd>k</kbd> | Message suivant, précédent de la conversation |
| <kbd>;</kbd> puis une lettre | Aller à un dossier : <kbd>i</kbd> Inbox, <kbd>q</kbd> Quarantine, <kbd>t</kbd> Todo, <kbd>w</kbd> Waiting, <kbd>a</kbd> Archive, <kbd>o</kbd> Travail, <kbd>m</kbd> All Mail… |
| <kbd>@</kbd> | Choisir un compte, ou tous |
| <kbd>Échap</kbd> | Revenir, fermer un panneau, effacer les marques |

## Agir sur le courrier

Les actions s'appliquent aux conversations marquées s'il y en a, sinon à celle sous le curseur.

| Touche | Action |
| --- | --- |
| <kbd>J</kbd> <kbd>K</kbd> | Marquer cette conversation et avancer, pour agir sur plusieurs à la fois |
| <kbd>d</kbd> | Fait : archiver (en Quarantine : supprimer) |
| <kbd>m</kbd> puis une lettre | Déplacer : <kbd>t</kbd> Todo, <kbd>w</kbd> Waiting, <kbd>n</kbd> Newsletter, <kbd>p</kbd> Paperwork… |
| <kbd>Suppr</kbd> | Mettre dans Deleted |
| <kbd>z</kbd> | Annuler le dernier déplacement ou la dernière décision |
| <kbd>u</kbd> | Lu ou non lu |
| <kbd>*</kbd> | Drapeau |
| <kbd>t</kbd> | Ajouter ou retirer un tag |
| <kbd>g</kbd> | Ajouter la personne à un groupe de contacts, ou l'en retirer |
| <kbd>⌘</kbd> <kbd>U</kbd> | Se désabonner de la newsletter |

## Lire

| Touche | Action |
| --- | --- |
| <kbd>l</kbd> | Liens, pièces jointes, numéros de téléphone et code de confirmation du mail |
| <kbd>T</kbd> | Tout afficher (citations, signatures, messages repliés), ou revenir à la vue simple |
| <kbd>S</kbd> | Sauter au texte après la prochaine citation |
| <kbd>v</kbd> <kbd>h</kbd> | Vue texte ou HTML |
| <kbd>v</kbd> <kbd>i</kbd> | Charger les images distantes |
| <kbd>⌃</kbd> <kbd>c</kbd> | La fiche de l'expéditeur dans Contacts |
| <kbd>⌃</kbd> <kbd>⇧</kbd> <kbd>c</kbd> | Tous les mails de l'expéditeur |

## Écrire

| Touche | Action |
| --- | --- |
| <kbd>r</kbd> | Répondre à tous |
| <kbd>R</kbd> | Répondre à l'expéditeur seul |
| <kbd>F</kbd> | Transférer |
| <kbd>c</kbd> | Nouveau mail |
| <kbd>⌘</kbd> <kbd>↩</kbd> | Envoyer. Vous avez cinq secondes pour annuler avec <kbd>z</kbd> |
| <kbd>⇧</kbd> <kbd>⌘</kbd> <kbd>↩</kbd> | Choisir où ranger la conversation, puis envoyer |
| <kbd>Échap</kbd> | Fermer et garder le brouillon |
| <kbd>⌘</kbd> <kbd>Échap</kbd> | Abandonner le brouillon |

## Trouver

| Touche | Action |
| --- | --- |
| <kbd>/</kbd> | Chercher partout |
| <kbd>f</kbd> | Filtrer la liste : non lus, drapeau, de, à, date, pièces jointes… |

Voir [Recherche et filtres](/fr/docs/search/).

## La souris

Tout fonctionne aussi à la souris. Un clic sélectionne une conversation, <kbd>⌘</kbd>-clic la marque ou la démarque, <kbd>⇧</kbd>-clic marque une plage. Les blocs de la barre d'état, en bas de la fenêtre, ouvrent les mêmes menus que leurs touches.
